# ИИ-команда для коротких роликов: скиллы и устройство системы Kossolab

Бесплатно. Для **Claude Code** и **Codex**, на **Mac** и **Windows**.

На канале **Kossolab** (@kossolab в YouTube и Instagram) ролики делает команда ИИ-агентов: ищет новости, пишет
тексты, режет дубли, подбирает картинки, проверяет, выкладывает и отвечает на комментарии. Человек выбирает
новость, записывает себя на телефон и говорит «да» или «нет».

Здесь лежит то, на чём это держится:
1. **Пачка готовых скиллов**: монтаж, звук, субтитры, графика и тексты. Все с открытым кодом, все ставятся одним промптом.
2. **Как устроена наша система**: 6 ролей и 41 шаг, кто что делает и как работа переходит от шага к шагу.
3. **Скилл, который делает скиллы для шагов.** Самое интересное, по нему собрана вся наша команда.
4. **Наш писатель текстов по новостям**: тексты на минуту с крючком в начале и без воды.

## Промпт: вставь своему агенту

Создай пустую папку, открой в ней Claude Code или Codex и вставь:

```
Поставь мне скиллы для ИИ-команды коротких роликов (набор Kossolab).
1) Проверь, что есть Node.js (команда npx) и git. Нет — поставь сам под мою систему:
   Mac — brew install node git (нет brew — https://brew.sh);
   Windows — winget install OpenJS.NodeJS.LTS и winget install Git.Git, потом открой новый терминал.
   Для монтажа поставь ещё ffmpeg: Mac — brew install ffmpeg, Windows — winget install --id Gyan.FFmpeg -e.
2) Поставь скиллы в эту папку сразу для Claude Code и Codex, каждый командой с ключами -a claude-code codex --copy -y:
   npx -y skills add OpenMontageInc/OpenMontage -s ffmpeg video-edit speech-to-text sound-effects video-download video-understand -a claude-code codex --copy -y
   npx -y skills add heygen-com/hyperframes -s hyperframes hyperframes-cli hyperframes-registry media-use -a claude-code codex --copy -y
   npx -y skills add Comandosai/ai-komanda-skills -a claude-code codex --copy -y
   npx -y skills add evgeniy2311/kossolab-starter -a claude-code codex --copy -y
   npx -y skills add smixs/humanizer-ru -a claude-code codex --copy -y
   npx -y skills add artemnovitckii/content-skills -a claude-code codex --copy -y
   Одна команда упала — остальные всё равно ставь, в конце скажи, что не встало и почему.
   Создай в этой папке четыре папки: «Исходники» (мои записи), «Референсы» (ролики, на чей стиль равняемся),
   «Материалы» (картинки и видео для вставок), «Готовые» (готовые ролики).
3) Скачай описание системы: https://github.com/evgeniy2311/kossolab-starter/blob/main/README.md — прочитай разделы
   «Как устроена система» и «Как построить свою команду».
4) Скажи мне простыми словами, что поставилось, и предложи начать: «разбери мой процесс» (скилл razbor-processa).
```

## Промпты из ролика

**Шаг 1.** Поставь Claude Code (https://claude.com/claude-code) или Codex (https://developers.openai.com/codex)
приложением на компьютер, не в браузере.
**Шаг 2.** Заведи папку «ИИ-монтаж», открой новый чат, выбери «Локально» и укажи эту папку.
**Шаг 3.** Вставь промпт установки (выше): агент поставит инструменты и скиллы и заведёт папки.

**Шаг 4. Стиль.** Положи в «Референсы» 4–5 роликов (свои или автора, на которого хочешь быть похож) и вставь:
```
Изучи ролики в папке «Референсы». Не на глаз, а с замерами: ffmpeg для склеек и длины, распознавание речи для темпа и пауз.
Запиши в «брендбук.md» с цифрами и 2–3 кадрами-примерами на каждый пункт:
- первые 3 секунды: чем цепляют (кадр, фраза, текст на экране, звук);
- темп: средняя длина куска между склейками, паузы между фразами, скорость речи (слов в минуту), длина ролика;
- субтитры: шрифт, размер, цвет, где стоят, сколько слов в строке, как подсвечено текущее слово;
- кадр: зумы и сдвиги (как часто и насколько), где лицо в кадре;
- вставки: как часто и какие (видео, картинки, графика, текст), сколько держатся;
- звук: музыка (жанр, громкость под голосом), звуки на действиях;
- цвет и общее настроение.
Потом смонтируй по брендбуку 10 секунд из моей записи в «Исходниках» и покажи мне.
Когда скажу «ок» — монтируй по брендбуку всегда. Каждую мою правку дописывай в брендбук моими словами, чтобы не повторять ошибку.
```

**Шаг 5. Монтаж.** Сними себя как обычно (ошибся — просто повтори фразу), положи запись в «Исходники» и вставь:
```
Смонтируй вертикальный ролик 1080×1920 из нового файла в «Исходниках» по «брендбук.md».
- В записи есть дубли: бери последний полный дубль каждой фразы, даже если он сказан не слово в слово.
- Вырежи паузы, вдохи, оговорки и всё между фразами. Пауза на стыке не больше 0,2 секунды.
  Края режь по настоящему звуку голоса, а не по тишине и не по границам слов из распознавания.
- Субтитры по словам, как сказано, текущее слово подсвечено.
- Вставки из «Материалов», графику и звуки ставь туда, где они показывают то, что я говорю в эту секунду.
- Сначала покажи раскадровку картинками: секунда, фраза, что на экране. После моего «ок» собери в «Готовые».
- Перед показом отдай ролик на проверку отдельному агенту (не себе): паузы длиннее 0,2 с, пропавшие слова,
  громкость (−14 LUFS), обрезанное лицо, субтитры поверх важного. Брак исправь, потом покажи мне.
```
Не нравится — скажи словами, как живому монтажёру: «на 12-й секунде пауза», «субтитры ниже». Запнёшься на любом шаге —
спроси у самого Claude Code или Codex и попроси объяснить простым языком.

### Строить свою команду: скилл, который делает скиллы для шагов
Это навыки практикума **«AI Команда»** Дмитрия Попова (COMANDOS AI), [открытый репозиторий](https://github.com/Comandosai/ai-komanda-skills).
По ним собрана вся наша система: каждый из 41 шага сначала делался руками с агентом, а потом превращался в навык.

| Скилл | Что делает | Как позвать |
|---|---|---|
| **`sozdat-navyk`** | **главный.** Превращает разговор, в котором ты с агентом что-то сделал, в навык шага: что на входе, что на выходе, «готово, если», «как выглядит халтура», проверка перед выдачей. Потом обновляет навык после прогонов | «создай навык из того, что мы сейчас сделали», «обнови навык ИМЯ» |
| `razbor-processa` | раскладывает твою работу на шаги, помечает каждый: скрипт, навык или человек; показывает, где выход одного шага становится входом следующего | «разбери мой процесс» |
| `rabochee-mesto` | разворачивает папки: правила, вход, выход, дела | «разверни моё рабочее место» |
| `nanyat-sotrudnika` | собирает из навыков роль («сотрудника») с паспортом | «найми сотрудника на мой процесс» |
| `mehanik` | читает журнал работы роли и говорит, какую строку в каком файле поправить, чтобы она перестала вставать | «разбери журнал и скажи, что чинить» |
| `naladit-komandu`, `svyazat-komandu`, `pokazat-dela` | связать роли в одну цепочку, запускать одной командой, видеть, где дело идёт само, а где его двигаешь ты | «налади команду», «свяжи команду», «покажи дела» |

## Как устроена система

### Шесть ролей, 41 шаг
| Роль | Шаги | Что делает | Где человек |
|---|---|---|---|
| **1. Разведчик** | 1–8 | каждый час собирает около 75 сайтов и 22 YouTube-канала, смотрит, что снимают конкуренты, отсеивает старое и дубли, оценивает темы, пишет карточки и присылает выпуск в Telegram | выбирает темы |
| **2. Редакция** | 9–14 | собирает досье и статьи целиком, пишет текст, сверяет каждый факт с источником, собирает суфлёр | записывает ролик по суфлёру |
| **3. Монтаж лица** | 15–21 | находит ролики в записи, выбирает дубли (где глаза в камеру), режет паузы по настоящему звуку, подбирает незаметные стыки, звук и цвет | решает перезапись, если надо |
| **4. Художник** | 22–27 | ищет настоящие видео по теме, отбирает лучшие моменты, пишет раскадровку «кадр под фразу», делает кадры: генерации, анимацию, стоки | — |
| **5. Сборка** | 28–33 | подгоняет сцены под слова записи, собирает верх и ролик, считает цифры, независимо проверяет | смотрит ролик |
| **6. Выпуск** | 34–41 | три обложки и слепой судья обложек, тексты публикации, выкладка по расписанию, замеры через 48 часов и 7 дней, разбор, ответы на комментарии | — |

### Из чего сделан каждый шаг
Каждый шаг одного из трёх типов:
- **СКРИПТ.** Всё, что можно посчитать: сбор новостей, паузы, громкость, склейка, выкладка. Программа без ИИ, быстро и одинаково каждый раз. Таких шагов у нас 16.
- **НАВЫК.** Там, где нужен вкус: оценить тему, написать текст, выбрать кадр, разобрать спорный дубль. ИИ работает по скиллу шага. Таких шагов 21.
- **ЧЕЛОВЕК.** Только решения: какую тему берём, запись, перезапись, «показываем». Таких шагов 4.

### Как работа переходит от шага к шагу
- **Одна папка на ролик («дело»).** Каждый шаг кладёт туда свой файл с номером (`11-tekst.md`, `16-dubli.md`), следующий шаг берёт его оттуда. Пересказа в чате нет, только файлы.
- **У каждого шага записано:** что он берёт, что отдаёт, какие разделы обязательно есть в результате, сколько минут ему можно.
- **Ворота.** Шаг сдаёт работу, а программа проверяет файл: все ли разделы на месте, сходятся ли цифры. Не сходится — шаг не сдан.
- **Проверяет другой.** Текст сверяет отдельный агент фактов, ролик смотрит отдельный проверяющий. Сам себя никто не принимает.
- **Один возврат, потом человек.** Проверка вернула работу один раз, исполнитель поправил. Не вышло и со второго раза — стоп, решает человек. Бесконечных кругов нет.
- **Новый исполнитель на каждый шаг.** Длинная сессия устаёт и путается, а свежий агент читает файлы дела и делает одну вещь.

### Правила, до которых мы дошли на своих ошибках
- **Тема важнее формулировок.** Сильную новость можно испортить, слабую не спасёт никакой текст.
- **Зритель ничего не знает о теме.** Каждое имя и цифра объяснены в той же фразе, на экране то, что звучит в эту секунду.
- **Последний дубль правильный.** Ошибся — повтори кусок с начала, программа возьмёт последний.
- **Ролик до 60 секунд.** Большая новость идёт двумя частями, сильные факты не режем.
- **Правки человека записываются его словами**, по секундам. Правится только названное, похваленное не трогают.

## Как построить свою команду

1. **Начни с одного места, которое болит** (например, монтаж). Скажи агенту «разбери мой процесс» (`razbor-processa`): получишь 5–7 шагов с пометками «скрипт / навык / человек».
2. **Сделай первый шаг руками вместе с агентом**, 2–3 раза на настоящей работе. Поправляй его словами, как поправил бы живого монтажёра.
3. **«Создай навык из того, что мы сейчас сделали»** (`sozdat-navyk`). Он спросит, как понять «готово» и как выглядит халтура, и сохранит шаг навыком.
4. Прогони навык на 3–5 новых задачах. Где споткнулся — «обнови навык ИМЯ» одной строкой.
5. Всё, что повторяется и считается (паузы, громкость, длина), проси агента вынести в скрипт: ИИ не должен считать на глаз.
6. Несколько навыков подряд — **«найми сотрудника»** (`nanyat-sotrudnika`). Роль начала вставать — **«разбери журнал и скажи, что чинить»** (`mehanik`).
7. Следующее место, которое болит, — снова с шага 1.

Мы шли так полтора месяца: сначала монтаж, потом тексты, картинки, обложки, выкладка, аналитика. Сразу всю систему не строй, иначе получится 40 шагов, которые не работают.
